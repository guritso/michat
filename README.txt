MiChat

MiChat is a peer-to-peer chat mod for Mindustry. It lets players on the same
VPN chat while playing separate single-player or campaign sessions, without
joining or hosting the same game server.

MiChat also works alongside the native chat in hosted games and lets players
share schematics. It supports desktop and Android.

All players must be connected to the same VPN network and have MiChat installed.
